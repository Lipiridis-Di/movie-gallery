# Кино-галерея — to-do / roadmap

_Документ планирования (шаг 1 из 3). Финальный список готового — в README.md проекта._

## Идея

Сайт-каталог фильмов в духе Кинопоиска: просмотр, поиск, фильтрация, карточка фильма, избранное. Не клон один-в-один, а pet-проект, где приоритет — прокачать инструменты, которых не было в предыдущих проектах.

## Почему такой стек

**Фаза 1 — ядро проекта:**

- **TypeScript** по всему проекту — раньше проходили только в теории , здесь применяем на реальном коде: типизация компонентов, пропсов, ответов API.
- **React Router** — каталогу нужны страницы `/`, `/movie/:id`, `/search` и т.д., так что роутинг учится не абстрактно, а на реальной задаче.
- **TMDB API** — бесплатный, стабильный, с богатой документацией; данные о фильмах, постеры, трейлеры, актёры.
- **Tailwind CSS** — раньше был только в теории; на практике даёт быстро собрать интерфейс, не увязая в ручном CSS.
- **Zustand** — стейт-менеджмент попроще Redux Toolkit по API, но с тем же принципом; хранит избранное/watchlist и UI-состояние (фильтры, поиск).

**Фаза 2 — надстройки после того, как MVP заработает:**

- **Тестирование (Vitest + React Testing Library)** — писать тесты на пустой каркас малополезно, добавляем, когда есть что тестировать.
- **Supabase (или Firebase) как бэкенд** — авторизация и облачное хранение избранного/рейтингов вместо localStorage. Отдельный, ценный навык — интеграция с реальным BaaS.

## Функциональность MVP (фаза 1)

1. Главная страница — популярные/трендовые фильмы (грид карточек, постер, название, рейтинг, год).
2. Поиск фильмов по названию.
3. Фильтрация по жанру и году.
4. Страница фильма — постер, описание, рейтинг, жанры, актёры, трейлер (если есть в TMDB).
5. Избранное / «посмотреть позже» — хранится в localStorage через Zustand + persist.
6. Пагинация или infinite scroll в каталоге.
7. Адаптивная вёрстка (мобильный / десктоп).
8. Состояния загрузки / ошибок / пустого результата.

## Что осознанно не входит в MVP

- Авторизация и облачное хранение (фаза 2).
- Отзывы/рейтинги от пользователя.
- Тесты (фаза 2).
- SSR/Next.js — решили не трогать в этом проекте.

## Этапы разработки

1. **Сетап проекта** — Vite + React + TypeScript, ESLint/Prettier, Tailwind, структура папок.
2. **API-слой и типы** — обёртка над TMDB API, TS-типы для ответов, `.env` для ключа.
3. **Роутинг и скелет страниц** — React Router, layout, навигация.
4. **Каталог фильмов** — список/грид, загрузка популярных фильмов, состояния загрузки/ошибки.
5. **Поиск и фильтры** — поиск по названию, фильтр по жанру/году.
6. **Страница фильма** — детальная информация, трейлер, актёры.
7. **Избранное** — Zustand store + persist в localStorage, UI для добавления/удаления.
8. **Полировка** — адаптивность, пустые состояния, доступность (базовая), деплой
9. _(Фаза 2)_ — тесты ключевых компонентов и хуков.
10. _(Фаза 2)_ — миграция избранного на Supabase + авторизация.
